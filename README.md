# AIVIO ERP — презентация для партнёров

Сайт-презентация (коммерческое предложение) системы управления застройщиком
[AIVIO ERP](https://crm-building.adamtech.dev). 12 слайдов, на каждом процедурная
3D-сцена жилого комплекса «Ала-Тоо Residence»: камера облетает дом и заходит внутрь.

| Слайд | Сцена |
|---|---|
| Начало | дом с волнистыми балконами, бронзой и подсвеченной короной |
| Проблема | кабинет руководителя: шесть мониторов, шесть разных программ |
| Решение | мониторы гаснут, на столе открывается один ноутбук с AIVIO |
| Продажи | ноутбук вылетает и встаёт рядом с домом, на фасаде светятся квартиры с шахматки |
| ИИ и звонки | офис продаж в лобби, от менеджеров линии идут в систему на видеостене |
| Документы | стол с актом приёма-передачи, на нём появляется печать ЭЦП |
| Финансы | фасад заливается до уровня освоенного бюджета |
| Стройка | кран подаёт поддон на перекрытие, бригада варит, забивает, красит |
| Снабжение и персонал | склад на площадке, затем турникет с Face ID у входа |
| Жильцы, Руководителю, Сотрудничество | дом вечером, связи интеграций, финальный кадр |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # сборка в dist/
```

## Где что править

- **Тексты слайдов** — `index.html`, каждый `<section class="slide">` — один слайд.
- **Камера, состояние сцены, выноски** — `src/slides.js`: на слайд одно состояние (`state`),
  поправки для телефонов (`mobile`), дополнительные пролёты камеры (`then`) и подписи (`callouts`).
- **Здание** — `src/scene/building.js`; кабинет — `office.js`; лобби (продажи, документы,
  турникеты) — `lobby.js`; стройплощадка — `site.js`; окружение — `world.js`.
- **Мебель, устройства, люди** — `props.js`, `people.js`; экраны «старых программ» — `screens.js`.
- **Скриншоты продукта** — `public/ui/` (`tex-*.webp` — для 3D-экранов, `ui-*.webp` — карточки).

## Плавность

- Под прелоадером компилируются все шейдеры, загружаются все текстуры и один раз
  отрисовываются все слайды, поэтому при первом показе ничего не догружается.
- Никакой буфер вершин не переписывается каждый кадр: искры сварки и линии к квартирам
  считаются в шейдерах (запись в буфер, который ещё рисует GPU, останавливала весь кадр).
- Стекло непрозрачное везде, кроме лобби и офиса, через которые пролетает камера.
- Мебель и люди в лобби рисуются только вблизи; недостроенные этажи не рисуются вовсе.
- Сглаживание FXAA, свечение (bloom) в половинном разрешении. Если устройство не успевает,
  сначала отключается свечение, затем снижается разрешение.

Параметры для сравнения качества: `?msaa=4`, `?bloom=0`, `?fxaa=0`, `?debug`.
