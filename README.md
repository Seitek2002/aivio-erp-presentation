# AIVIO ERP — презентация для партнёров

Сайт-презентация (коммерческое предложение) системы управления застройщиком
[AIVIO ERP](https://crm-building.adamtech.dev). 12 слайдов; на каждом процедурная
3D-модель жилого комплекса меняет состояние под тему слайда:

| Слайд | Что делает здание |
|---|---|
| Проблема | этажи разлетаются, к каждому подписан отдельный разрозненный инструмент |
| Решение | этажи собираются обратно, модули системы подписаны на уровнях |
| Продажи | фасад превращается в шахматку: свободно, бронь, продано |
| Финансы | фасад заливается до уровня освоенного бюджета |
| Стройка | монолит до 11-го этажа, выше чертёж, рядом башенный кран |
| Руководителю | вид сверху, от здания расходятся связи интеграций |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # сборка в dist/
```

## Где что править

- **Тексты слайдов** — `index.html`, каждый `<section class="slide">` — один слайд.
- **Камера, режим здания и выноски** — `src/slides.js`: на каждый слайд одно состояние
  сцены (`state`), поправки для телефонов (`mobile`) и подписи на модели (`callouts`).
- **Модель здания** — `src/scene/building.js`, окружение — `src/scene/world.js`.
- **Скриншоты интерфейса** — `public/ui/*.webp`.
- **Стили** — `src/style.css`.

## Плавность

- Все шейдеры компилируются, а все слайды и выноски один раз отрисовываются под
  прелоадером, поэтому при первом показе ничего не «догружается» посреди анимации.
- Карточки со скриншотами никогда не становятся полностью прозрачными (0.002),
  браузер держит их текстуры готовыми.
- Разрешение canvas ограничено бюджетом пикселей и снижается автоматически,
  если устройство не успевает рисовать 60 кадров.

## Публикация
